PatchWhy

Paste a unified diff (from diff -u or git diff). Optionally paste the file it should apply to. See whether the hunk counts are right, and which hunk fails and why.
The reader and the applier were checked on 1,500 generated diffs (4,314 checks, 0 differences): applying a diff to its own original gives the new file, and on altered originals the result matches GNU patch 2.7.6 with --fuzz=0, including which cases are rejected. Corrupted hunk counts were always caught. Git-specific features (renames, binary patches, fuzz above 0, whitespace options) are not applied. Runs in your browser; nothing is uploaded.
